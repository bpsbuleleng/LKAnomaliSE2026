# Pengelompokan desa untuk ekspor `keluarga` / `roster_ak` / `roster_meteran`

Dihasilkan dari data Query 2 (`query_hitung_baris_per_kecamatan.sql`), 2026-08-08.
Bin-packing per kecamatan, target `n_estimasi_flagged_atas_proxy` ≤ 8000/grup
(beri jarak dari hard-cap SQL Lab ±9000). **Proxy = estimasi kasar** (dipakai
K1/K3 juga), jumlah baris ekspor SESUNGGUHNYA bisa sedikit beda — kalau satu
grup ternyata >9000 di query asli, pindahkan 1-2 desa terakhir grup itu ke
grup lain di kecamatan yang sama dan jalankan ulang.

Total: **21 grup** untuk 148 desa / 9 kecamatan (jauh lebih sedikit dari
148 putaran per-desa).

Cara pakai: salin daftar `IN (...)` satu grup, tempel ke baris filter yang
sudah di-uncomment di `query_ekspor_fasih_keluarga.sql` / `roster_ak.sql` /
`roster_meteran.sql` (filter `SUBSTR(...,1,10) IN (...)`), jalankan,
lanjut §2 Cara A (`node scripts/fasih-import-csv.js ...`) di TUTORIAL_IMPOR_FASIH.md.
